## 六、趋势总结与建议

0. **国内 Coding Plan 进入「涨价与分化」阶段**：智谱 7/30 一次性把三档价格拉高 130%–261%，同时用「放开限购 + 积分透明化 + 周末低峰」换取合法性——这标志国产 Coding Plan **告别低价倾销、开始向海外价格看齐**（新版 Pro ¥538 ≈ \$74，已接近 Z.ai 国际版 \$72）。与此同时百度、腾讯把产品彻底 Token Plan 化，火山、小米则靠促销与夜间折扣继续抢用户。**「低价但抢不到」正在被「买得到但更贵」取代。**
1. **海外反向降价，Token 价格战白热化**：OpenAI 7/31 把 Luna 打到 \$0.2/\$1.2（−80%），把「支撑 Agent 干活的模型」卖到过去简单小模型的价位。压力来自企业控本 + Kimi K3 等中国开源模型逼近前沿。**国内涨价、海外降价，价差窗口正在收窄。**
2. **计费范式迁移完成**：从「按请求数」全面转向「按 Token / Credit / 积分计费」。Copilot（AI Credits）、Cursor（credit 池）、Codex（token 积分）、智谱（积分制）、百度/阿里/腾讯/小米（Token Plan）殊途同归；行业层面已成立 **Tokenomics Foundation** 推动统一度量。
3. **「分时定价」成为新变量**：智谱周末与非高峰 0.5×、小米夜间 0.8×、阿里云夜间 0.2 折——**把重活挪到夜间/周末，等于白拿 20%–80% 折扣**，这是当前最容易被忽略的省钱杠杆。
4. **订阅价只是地板价**：Copilot 首周期证明重度用户真实月支出常是标价的 **10–50×**。务必看「真实成本」而非「挂牌价」。
5. **模型路由 = 省钱关键**：同一工具内选便宜模型（Luna / Haiku / GLM-4.7 / 自有模型）可省数倍；把重活留给 Opus/Sol/GLM-5.2。
6. **Agent-first 成为产品共识**：智谱 ZCode（ADE）、Cursor Composer 2.5 + Mission Control、Copilot Agent Skills GA 同期落地，人类角色从「创作者」转为「审查者」——**审查判断力正在取代编码速度成为核心竞争力**。
7. **选型建议**：
   - 个人轻度 → Copilot Free / Trae Free / Gemini CLI（1000 req/天）/ 百度千帆 Mini **¥4.9**
   - 日常主力（国内）→ 百度千帆 Lite **¥19.9**（4200 万 Token 无限流）或火山方舟 Lite **¥9.9**（8/27 前锁定）
